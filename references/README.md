# Reference Guide

This directory exists to guide taste and implementation.

Do not copy unrelated UI just because it looks impressive.

## Primary references

### Refero Styles
https://styles.refero.design/

Use for:

- design-system direction;
- typography;
- spacing;
- color logic;
- component language.

### AppShot Gallery
https://www.appshot.gallery/

Use for:

- mobile app patterns;
- fitness/health app interactions;
- bottom navigation;
- timers;
- logging flows;
- mobile information density.

### shadcn/ui
https://ui.shadcn.com/

Use for:

- implementation primitives;
- accessible component structure;
- drawers/sheets;
- dialogs;
- buttons;
- charts;
- progress;
- forms.

### 21st.dev
https://21st.dev/

Use for:

- occasional compatible React/Tailwind component patterns;
- inspiration beyond basic shadcn components.

### Motion Primitives
https://motion-primitives.com/

Use for:

- restrained micro-interactions;
- layout transitions;
- completion states;
- drawer transitions.

### Component Gallery
https://component.gallery/

Use for:

- comparing established UI patterns;
- choosing appropriate controls;
- avoiding invented interaction patterns.
